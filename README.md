## 📌 Project Overview
**CareerConnect** is a robust and scalable Job Portal application built using **Java and Spring Boot**. It acts as a bridge between job seekers and recruiters, providing a seamless platform for posting jobs, searching for opportunities, and managing applications. 

## Key Features
* **User Roles & Authentication:** Secure login and registration for both Candidates and Recruiters.
* **Job Management:** Recruiters can post, edit, and delete job listings.
* **Smart Job Search:** Candidates can browse and filter jobs based on categories and roles.
* **Application Tracking:** Candidates can apply for jobs and track their application status directly from their dashboard.
* **Scalable Architecture:** Built with Spring Boot adhering to the MVC pattern and RESTful principles.

## 🛠️ Technology Stack
* **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate
* **Database:** MySQL
* **Frontend:** Thymeleaf / HTML5 / CSS3 / JavaScript
* **Tools:** Maven, Git

## ⚙️ How to Run Locally

1. **Clone the repository:**
   git clone [https://github.com/ExorXis/CareerConnect.git](https://github.com/ExorXis/CareerConnect.git)
2. **Setup Database:**
   * Create a MySQL database named career_connect_db.
   * Update the application.properties file in src/main/resources with your MySQL username and password.
3. **Run the Application:**
   * Navigate to the project directory and run the application using Maven or your preferred IDE (Eclipse/IntelliJ/STS).
   * The application will start on http://localhost:8080.
